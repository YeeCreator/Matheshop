## 4. 功能需求（MVP）

- **Engine**：计算引擎；当前提供 Python 引擎，可对表达式求值
- **Edge**：连接两端口的连线
- **Formula**：公式对象，使用 KaTeX 渲染，可拖拽
- **Cell**：可编辑内容块，支持嵌套/组合
- **Camera**：`x/y/zoom`，决定世界坐标与屏幕坐标变换
- **Canvas**：画布容器，支持 camera 平移/缩放

## 2. 用户与使用场景

### 1.3 非目标（当前阶段不做）

- 为后续“符号计算/局部子树编辑/图结构推理”打下工程与交互基础
- 支持基础数学表达式输入与渲染，并能一键求值（面向演示/探索）
- 提供一个可用的数学白板 MVP：易创建、易编辑、可视化连接

### 1.2 产品目标

- 计算：提供内置 Python 引擎求值（FastAPI），并预留 TS 引擎/外接引擎
- 内容：以文本 + KaTeX 为主，逐步引入“表达式 AST/token 级别编辑”
- 交互：类似 Obsidian Canvas / draw.io / Figma 的 camera 平移/缩放体验

当前阶段以“交互与工程结构的可演进性”为核心：

Matheshop 是一个基于 Canvas 的轻量数学白板原型，支持在画布上创建可编辑单元框（Cell）、渲染 KaTeX 公式、以及在单元框之间连线。
